## 📌 Tentang S.Portofolio

**S.Portofolio (SERAYA VISUAL)** adalah aplikasi web manajemen portofolio interaktif dan *Client Area* yang dirancang untuk mengelola layanan profesional, portofolio proyek, serta preferensi tampilan web secara dinamis dari **Dashboard Admin Panel**.

Aplikasi ini dibangun menggunakan framework **Laravel** dengan arsitektur **Key-Value Store Settings** untuk memberikan kemudahan kustomisasi tanpa perlu mengubah kode sumber (*hardcode*).

---

## ✨ Fitur Utama

- 🎨 **Dynamic Web & SEO Management**: Atur nama brand, title browser, meta deskripsi, meta keywords, logo, dan favicon langsung dari Dashboard Admin.
- 🔐 **Custom Authentication & Login Appearance**: Tampilan halaman Login & Register yang dapat disesuaikan dengan latar belakang animasi GIF dinamis, ucapan salam kustom, dan versi aplikasi.
- 👥 **Client Area & Admin Panel Layouts**: Pemisahan antarmuka yang rapi untuk pengguna/klien dan pengelola sistem.
- 🌙 **Persistent Dark Mode Support**: Pengaturan mode gelap yang tersimpan otomatis menggunakan `localStorage`.
- 🌐 **Dynamic Navbar & Footer Settings**: Menu navigasi dan informasi footer yang dapat disesuaikan dari dashboard.
